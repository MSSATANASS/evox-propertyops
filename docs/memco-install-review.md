# Revisión previa de instalación — Memco Shared Memory

La ficha de Claude Directory describe Memco Shared Memory como un conector de memoria compartida para equipos de humanos y agentes. Declara espacios de trabajo privados con control de acceso por roles y compatibilidad MCP entre distintos proveedores de agentes.

La ficha enumera capacidades para crear, enriquecer, buscar y revertir memorias, además de describir dominios y compartir retroalimentación. Esas funciones pueden almacenar o recuperar conocimiento interno, por lo que deben tratarse como acceso a datos sensibles.

Claude Directory señala expresamente que los conectores comunitarios pasan revisiones automatizadas, pero no están verificados por Anthropic ni garantizados; solo deben conectarse cuando se confía en el desarrollador. La página pública no expuso el endpoint MCP, el proveedor de identidad ni el comando de instalación necesarios para instalarlo en la computadora conectada.

Fuente: https://claude.ai/directory/memco-shared-memory

El sitio oficial de Memco describe el producto como una capa de memoria compartida entre modelos, herramientas, IDEs y equipos. Indica que las lecciones se revisan antes de reutilizarse, conservan procedencia y pueden aplicarse con límites de alcance. También declara que no almacena repositorios completos, sino lecciones breves y acotadas; estas afirmaciones son del proveedor y no sustituyen una revisión de configuración.[1]

La página oficial enlaza a `https://docs.memco.ai` y a Spark para registro. Sin embargo, la documentación extraída no contiene el endpoint MCP, el flujo de autenticación ni un instalador local verificable. Por tanto, no se debe instalar ni conectar hasta obtener desde el portal o documentación oficial el método exacto, el proveedor de identidad, la URL MCP y los permisos solicitados.

[1] https://www.memco.ai
